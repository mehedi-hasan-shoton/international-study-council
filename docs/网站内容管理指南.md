# 网站内容管理指南 —— 给没有任何代码基础的你

网站已经上线：**https://international-study-council.vercel.app**
域名（可选，后续绑定）：**internationalstudycouncil.com**

这份指南只讲一件事：**以后你想改网站上的任何文字、图片、视频，都在哪里点。**
不需要代码，不需要命令行，浏览器里点几下就行。

---

## 0. 先做一件事：开启图片/视频上传（5 分钟，只做一次）

网站默认可以把图片传到网上，但需要一个"仓库钥匙"。没配之前，后台上传图片会失败。

**操作（用同学的 Vercel 账号）：**

1. 打开 https://vercel.com/international-study-council/international-study-council
2. 顶部点 **Storage** → **Create** → 选 **Blob** → 名字随便起（如 `isc-uploads`）→ Create
3. 创建后页面会提示 **Connect to Project**，选中 `international-study-council` → Connect
4. 到 **Deployments** 页面，最新一次部署右侧 **⋯ → Redeploy**（等约 1 分钟）

做完这一步，后台上传图片、PDF、海报都能用了（单个文件最大 8 MB）。

> 不配也能用：图片可以先传到任意图床（如 imgur），再把链接粘贴进后台的"图片"输入框。

## 2. 你能做什么（按使用频率排序）

### 2.1 改页面上的文字（Pages → 页面 → 区块）

网站每个页面都是由一个个"区块"搭起来的：大标题、服务列表、价格表、问答、联系方式……

- **Pages** → 点你想改的页面（如 `home`、`services`、`about`）→ 看到这个页面所有区块
- 每个区块右边可以：**编辑**（改文字）、**上移/下移**（调整顺序）、**隐藏**（临时下线）、**删除**
- 想加新区块：页面底部 **Add block** → 选类型（标题 / 文字 / 图片网格 / 视频 / 问答 / 表格 / 团队 / 价目表 / 付款方式…）→ 填内容 → 保存

常用区块类型对照：

| 你想放什么 | 选这个区块 |
|---|---|
| 一段标题+正文 | Text section |
| 图片九宫格（海报、活动照片） | Gallery |
| YouTube / Bilibili 视频 | Video（粘贴视频链接即可） |
| 常见问答 | FAQ |
| 团队成员的介绍卡 | Team（内容来自下方 2.3） |
| 服务价目 | Fee table / Service list（内容来自 2.2） |
| 收款账号 | Payment methods |

### 2.2 改服务和价格（Services）

左侧 **Services** → 每行是一个服务 → 点 **Edit**：

- `Fee (as shown)`：显示在网站上的价格原文，例如 `€30 / BDT 2,500`
- `Fee amount` + `Currency`：只影响"自己搭配方案"时的自动合计
- 改完 **Save**。价格表、服务卡片、搭配计算器**全部同步更新**。

当前 6 项服务（以《ISC Services & Fees》收费文件为准）：
Career Counselling €30 · Eligibility Check €30 · CV €30 · SOP €30 · CV+SOP €50 · Full Package €1,000。

### 2.3 管理团队成员（Advisors）

左侧 **Advisors** → **New** 或点已有的人：

- `Photo`：上传照片（正方形最好）
- `Intro video URL`：粘贴 YouTube 链接——**没传照片时，网站自动播放这个视频**
- `Role` / `Focus` / `Short biography`：头衔、负责方向、简介
- **Save** 后自动出现在"Who we are"页面的团队区。

### 2.4 上传资料给学员（Resources 页）

**Pages → resources** 这个页面就是给学员下载资料的地方，已经预留好位置：

- `Gallery` 区块：**Add image** 传海报/传单，一行一个
- `Video` 区块：粘贴 YouTube 链接（ webinar 录像）
- `Text section`：写说明文字

传完保存，前台 `Resources` 页立即更新。

左侧 **Settings**：

- `Social`：LinkedIn / Facebook / Instagram / YouTube 链接
- 当前已填：邮箱 `internationalstudycouncil2025@gmail.com`，WhatsApp 用官方商业号链接

## 3. 安全与运维（给同学，非技术）

1. **密码**：后台密码就是网站钥匙，不要发给无关人员；建议每半年换一次（改 Vercel 的 `SEED_ADMIN_PASSWORD` 后 Redeploy）。
2. **改坏了怎么办**：每个区块都能 **Delete / 隐藏**；整页改坏了可以找 Haijun 从 GitHub 恢复（代码在 github.com/mehedi-hasan-shoton/international-study-council）。
3. **不要动**：Vercel 里的 `DATABASE_URL`、`AUTH_SECRET`——这两个是数据库和登录密钥，改了网站会打不开。
4. **换域名**：见 Haijun 给的域名绑定步骤（Godaddy DNS + Vercel Domains）。

## 4. 常见问题

**Q：我改了后台，网站上是立即生效吗？**
是。后台就是直接改数据库，前台实时读取，延迟不超过 1 秒。

**Q：上传图片报错 "cannot write uploads to disk"？**
说明第 0 步没做。按第 0 步连接 Vercel Blob，然后 Redeploy。

**Q：视频支持哪些网站？**
YouTube 和 Vimeo 的链接都支持，粘贴播放页地址即可（不用懂嵌入代码）。

**Q：价格显示欧元符号错了 / 想改成美元？**
Services 里每条服务都有 `Currency` 字段，改成 USD 后所有合计和标签自动变。

**Q：想新增一整页（比如"成功案例"）怎么办？**
Pages → New page → 填标题和slug → 加区块 → 保存。把 `Show in nav` 打开，导航栏就会出现这一页。
